### **文件哈希计算工具 - File Hash Calculator**  
**中英双语介绍 / English & Chinese Introduction**

### **🔹 中文介绍 / Chinese Introduction**  

#### **📌 项目概述**  
这是一个轻量级的 Windows 工具，允许用户通过右键菜单快速计算文件的 **MD5** 和 **SHA1** 哈希值。适用于文件校验、数据完整性检查和安全验证等场景。  

#### **✨ 功能特点**  
✅ **右键菜单集成** - 在文件右键菜单添加“计算哈希值”选项，一键运行  
✅ **双哈希计算** - 同时计算并显示 **MD5** 和 **SHA1** 值  
✅ **复制到剪贴板** - 支持一键复制哈希值，方便比对  
✅ **无复杂安装** - 只需编译 EXE 并添加注册表项，无需额外依赖  

#### **🛠 适用场景**  
- **文件校验**：确保下载的文件未被篡改  
- **数据安全**：验证敏感文件的完整性  
- **开发测试**：快速检查文件哈希，无需第三方工具  

#### **📥 使用方法**  
1. **编译程序**（使用 .NET SDK 9）  
2. **添加注册表项**（双击 `.reg` 文件）  
3. **右键文件** → 选择“计算哈希值”

### **🔹 English Introduction**  

#### **📌 Project Overview**  
A lightweight Windows tool that allows users to quickly calculate **MD5** and **SHA1** hashes of files via the right-click context menu. Ideal for file verification, data integrity checks, and security validation.  

#### **✨ Key Features**  
✅ **Right-Click Integration** - Adds a **"Calculate Hash"** option in the file context menu  
✅ **Dual Hash Calculation** - Computes both **MD5** and **SHA1** values  
✅ **Copy to Clipboard** - One-click copy for easy comparison  
✅ **No Complex Setup** - Just compile the EXE and add a registry entry  

#### **🛠 Use Cases**  
- **File Verification** - Ensure downloaded files are untampered  
- **Data Security** - Validate the integrity of sensitive files  
- **Development Testing** - Quickly check file hashes without third-party tools  

#### **📥 How to Use**  
1. **Compile the program** (using .NET SDK 9)  
2. **Add registry entry** (run the `.reg` file)  
3. **Right-click any file** → Select **"Calculate Hash"**
